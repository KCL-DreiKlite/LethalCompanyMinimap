# Changelog

## 1.2.0

- **All players in the lobby (host and clients) must now have this mod installed.** Players without it cannot join a lobby that uses it, and vice versa. This is required by the Thunderstore Lethal Company community rules for mods that give an advantage

## 1.1.1

- Fix the terrain contour map disappearing on the Minimap when outdoors
- Fix the Minimap showing only the moon info screen on non-host clients after a player joins mid-round (e.g. with late-join mods)

## 1.1.0

First release of the v80-compatible fork of [Tyzeron's Minimap mod](https://github.com/tyzeron/LethalCompanyMinimap).

- Compatibility with the game update v80
- The ship icon introduced in the newer game updates is now toggled together with the Ship Arrow
- The Ship Arrow now also follows radar boosters, not only players
- Version check now uses this fork's Thunderstore page (falls back to GitHub releases)

For changes up to 1.0.6, see the [original repository](https://github.com/tyzeron/LethalCompanyMinimap).
